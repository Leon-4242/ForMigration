Коржик — Telegram-бот для студенческого общежития (ДС / ДСЛ)
=============================================================

Стек: Python 3.11+, aiogram 3, SQLite, Google Sheets (gspread), APScheduler.


Быстрый старт
-------------

1. Создать .env в корне проекта:
       BOT_TOKEN=<токен от @BotFather>

2. Положить ключ Google Sheets в:
       data/auth/korjik-tgbot.json

3. Установить зависимости и запустить:
       python -m venv .venv && source .venv/bin/activate
       pip install -r requirements-dev.txt
       PYTHONPATH=src python src/main.py

Как устроен запуск
------------------

main.py
  └─ Application.initialize()
       ├─ SQLite: users, messages
       ├─ сервисы: Google Sheets, messenger, sync БД
       ├─ middleware → data["user"], data["messenger"], data["messages"], data["users"]
       ├─ роутеры: common → admin → echo (порядок важен)
       └─ scheduler: UpdateDatabaseTask
  └─ Application.start()
       ├─ scheduler.start()
       └─ bot.start(startup)  → polling

При старте: синхронизация messages.sqlite из Google Sheets, уведомление админов.


Поток данных
------------

Google Sheets  →  infrastructure/services/database.py  →  messages.sqlite
                                                          ↓
handlers (system/)  ←  middleware  ←  MessageService / UsersService
                                                          ↓
                                              MessengerService  →  Telegram


Команды бота (system/)
----------------------

Пользовательские:
    /start      — регистрация и приветствие
    /help       — справка (текст из БД)
    /feedback   — отзыв администраторам

Админские (нужен флаг admin в users.sqlite):
    /restart    — перезапуск бота
    /admin_help — справка для админа
    /set_admin  — назначить/снять админа
    /notify     — рассылка всем пользователям

Тексты команд хранятся в messages.sqlite (лист MESSAGES в Google Sheets).
Меню команд Telegram (setup_commands) пока закомментировано в application.py.

Статус modules/
---------------

Каталог modules/ — задел под доменную логику (общежитие, бытовые сервисы, горoscope).
Сейчас не импортируется из Application и содержит незавершённый код.
После доработки модули подключаются через новые роутеры в initialize_routers().
